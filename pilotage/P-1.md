# P-1 — retirer le dernier réglage de grammaire

**Point de départ** — les deux natures de la config sont identifiées, rien n'est mesuré ni retiré.

## Reste

### À mesurer d'abord
- [ ] Remplacer le motif `codes.chantier` par la liste des codes réellement déclarés
      dans `pilotage/` (plus ceux remontés d'un audit), et mesurer l'écart sur AGRAFES
      avant de garder le changement
- [ ] Vérifier le cas qui a motivé la manœuvre : avec le motif générique, `UTF-8` passe
      pour un code de chantier sur un dépôt tiers

### À trancher
- [ ] `index()` découvre dans `docs/` des codes que le dossier ne déclare pas ; avec un
      vocabulaire dérivé, ces liens disparaissent — décider si c'est une perte
- [ ] Retirer `codes` de la config une fois les deux points ci-dessus tranchés
- [ ] Séparer `documentation` en deux : le **nom du dossier** est de l'inventaire (il
      sert au démenti d'un `à venir`), les **motifs de fichiers** sont de la grammaire.
      Non déclaré, le nom ne rend pas le démenti muet — il le fait **sur-déclencher** :
      une note de conception compte alors comme du code
- [ ] Décider si `docs/` devient une convention imposée plutôt qu'une valeur déclarée
- [ ] `pastilles()` dans la vue code `docs/` en dur pour transformer un chemin en lien :
      la grammaire a fui jusque dans le navigateur, qui ne lit pas la config. Le dossier
      doit voyager dans le JSON

## Contexte

La config a deux natures mélangées : l'**inventaire** (chemins, branches, fichier sous
veille) qu'aucun outil ne peut deviner, et la **grammaire** (comment on écrit les codes,
quels fichiers portent quels documents) qui n'est adaptative que parce que l'outil a
appris à lire de la prose qu'il n'avait pas écrite.

L'inventaire reste. La grammaire doit disparaître : le vocabulaire des codes est déjà
dans le dossier, puisque chaque fiche déclare le sien. `rxCodes()` sait déjà construire
un motif à partir d'une liste — c'est `fourretout()` qui repasse par le motif générique.

Décidé le 2026-08-24 : rigidifier plutôt qu'adapter. Un seul objet, un seul cycle de vie.
